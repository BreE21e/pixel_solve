# 数字轰炸：CTF 像素画还原

一个使用 Python 和 Pillow 编写的 CTF 解题脚本。将题目中连续 9 天收到的数字作为像素横坐标，按天排列成 9 行，生成完整图片和带网格的分段图片，帮助读出隐藏的 flag。

## 题目背景

cloverdayssss 对 xing 进行了数字轰炸，xing 连续 9 天收到了一组组数字。

题目给出的提示是：

> xing：什么叫这是像素画啊？这最多也只能是个点啊……什么坐标轴？
>
> 温馨提示：方格上更清晰

完整数字已保存在 `pixel_solve.py` 的 `data` 变量中，无需另外准备输入文件。

## 解题思路

结合“像素画”“坐标轴”和“方格”的提示，可以尝试把每个数字当作一列的位置，把每天的数据当作一行。

- 第 1 天的数据放在最上面，第 9 天的数据放在最下面。
- 横坐标从 `0` 开始编号。
- 某个数字出现，就将对应位置涂黑；没有出现的位置保持白色。

例如，第 1 天包含 `25`、`31`、`32`，就将最上面一行中横坐标为 `25`、`31`、`32` 的方格涂黑。程序使用从 `0` 开始的行编号，因此这些位置对应 `(25, 0)`、`(31, 0)`、`(32, 0)`。

题目中的最大数字是 `146`，所以需要 `147` 列；共有 `9` 天，所以需要 `9` 行。填完方格后，黑块会组成字符。

这里使用图片坐标：原点在左上角，横坐标向右增加，行号向下增加。

## 环境与运行

需要 Python 3 和 Pillow。Pillow 是 Python 的图像处理库，脚本中的 `PIL` 来自这个库。

下载仓库后，在仓库文件夹中打开终端，先安装依赖：

```bash
python -m pip install -r requirements.txt
```

然后运行脚本：

```bash
python pixel_solve.py
```

也可以直接使用以下命令安装唯一的依赖：

```bash
python -m pip install Pillow
```

在 Windows 上，如果 Python 通过 `py` 命令启动，可以将上述命令中的 `python` 替换为 `py`。

正常运行后，终端会显示：

```text
Rendered 147 columns and 9 rows
```

图片会保存到运行命令时所在的目录。如果该目录中已经存在同名图片，程序会覆盖它们。

## 关键代码说明

### 1. 将每天的数字转换为集合

```python
rows = [set(map(int, line.split())) for line in data.splitlines()]
```

`splitlines()` 按行拆分数据，`split()` 按空白分出各个数字，`int` 将文本转换为整数，`set` 保存这一行需要涂黑的位置。

### 2. 计算图片宽度

```python
width = max(max(row) for row in rows) + 1
```

横坐标从 `0` 开始，因此最大横坐标 `146` 对应的是第 `147` 列，需要加 `1`。

### 3. 放大并绘制黑色方块

```python
for y, row in enumerate(rows):
    for x in row:
        draw.rectangle(
            (x * scale, y * scale,
             (x + 1) * scale - 1, (y + 1) * scale - 1),
            fill='black'
        )
```

`y` 表示所在行，`x` 表示数字对应的列。`scale = 12` 将每个逻辑像素放大成 `12 × 12` 的方块，方便观察。右边界和下边界减 `1`，是因为 Pillow 的矩形绘制包含边界像素。

## 解题结果（包含 flag）

图片中的字符可以读为：

```text
moectf{i5_7h1s_gr1d_ch4r?}
```

容易混淆的地方：

- 花括号后的第一个字符是小写字母 `i`，后面是数字 `5`。
- `7h1s` 和 `gr1d` 中使用数字 `1`。
- `ch4r` 中使用数字 `4`。
- 末尾的问号 `?` 是 flag 的一部分。

脚本负责把数据画成图片，flag 是观察图片后读出的；程序本身没有进行 OCR，也不会自动输出 flag。

## 修改数据时的注意事项

这是针对本题编写的脚本。完整图的宽度和行数根据输入数据计算，但分段展示图固定使用 `0–48`、`49–97`、`98–146` 三段，并按本题的 9 行布局。

如果换成其他题目的数据，需要同时调整分段范围、画布大小和分段间距。当前输入还要求每一行至少包含一个非负整数。
